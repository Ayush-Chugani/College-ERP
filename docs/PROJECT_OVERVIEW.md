# Project overview

SIMS is the Student Information Management System of GEC Haveri: a Next.js 15 web app on Supabase (PostgreSQL, Auth, Storage, Row Level Security), migrated from a 213-table MySQL schema (`SIMS-DatabaseWithoutLessonPlan.sql`).

## Modules built (screens + database)
Students, Employees, Admissions, Registration, Attendance, Timetable, Assessment and Results, Finance (read and refunds), Feedback, Mentoring, Grievances, Institution structure, Academic calendar, Curriculum and Courses, **Announcements**, **Student documents**, **Student activities and evidence**, **Staff profile and research**, **Users and roles**, **Audit log**, Dashboard.

## Not built
See RTM.md for the exact list: employee documents, most Student Finance workflows, MFA, notifications beyond announcements, the Lesson Plan tables (backlog).
